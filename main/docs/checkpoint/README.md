# DGAD checkpoint handoff

This folder contains the reviewed 50% checkpoint presentation and the evidence used to prepare it.

- `DGAD_50_Percent_Checkpoint_Presentation.pptx` is the 15-slide deck.
- `DGAD_Checkpoint_Status.md` records the reproduced dataset, training, test, live API, and dashboard evidence.
- `DGAD_Viva_Cheat_Sheet.md` contains defensible answers and source links for the viva.
- `DGAD_Design_Checkpoint.md` records the implementation and design audit.
- `DGAD_Score_Provenance.json` documents the mixed legacy result artifacts.
- `presentation_validation.json` is the finalizer receipt: 15 slides, package/layout checks passed, and the native chart on slide 9 validated.

The checkpoint deliberately reports Channel B's measured test AUC and its high NotInject false-positive rate. Channel A GPT-2 training and a complete real C/D holdout benchmark remain final-phase work.
